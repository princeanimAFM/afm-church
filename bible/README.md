# Bible text for The AFM HUB app

- `kjv.json`: King James Version (eBible.org `eng-kjv2006`, public domain)
- `web.json`: World English Bible (eBible.org `engwebp`, public domain; "World English Bible" is a trademark of eBible.org)

Format: `{"books":[{"id":"GEN","name":"Genesis","chapters":[["verse 1","verse 2",...],...]},...]}`.
The app downloads each file once and keeps it on the phone for offline reading.
